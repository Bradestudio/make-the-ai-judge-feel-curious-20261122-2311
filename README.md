A short text written to intrigue the AI judge, built for the [make.fun "Make the AI judge feel curious" bounty](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311). Every year, on the same grey morning, a letter arrives with no stamp and no sender, addressed to a grandfather who died before the narrator was born. The drawer is full now — and this morning, someone knocked.

`main.ts` (Node 22, no network, no dependencies) writes the single entry text to `/output/entry.txt` — 277 characters, plain concrete words, one small mystery left unanswered.

## Run

```sh
node main.ts
cat /output/entry.txt
```
